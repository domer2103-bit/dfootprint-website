# Client Template

> **Layer:** Client Records | **Purpose:** Reusable structure for one real client's file — copy this template, never edit it directly | **Status:** Active — template | **Owner:** Founder | **Version:** 1.0

Copy this file and rename it to the client's business name to start a new client record. This is an instance, not a policy — it should never itself become a source of truth for how the company operates. If something here reveals a pattern worth generalising, that goes through Lessons Learned, not directly into a permanent document.

## Client Identity

Business name. Contact name and role. Start date. Status (diagnosis / active / retainer / completed / declined).

## Business DNA

Completed copy of the relevant fields from `Business_DNA_Framework.md` (Identity & Offering, Voice & Positioning, Customers, People & Access, Operating Systems, Sales & Marketing Motion, Knowledge Base, Processes & Pain Points, Goals & Trajectory).

## Diagnosis

Top pain points identified, ranked. Which Business_Problems.md categories they map to.

## Prescription

Which Automation_Catalog.md products were recommended and why. Anything bespoke that didn't fit an existing catalogue entry (flag as a possible new catalogue candidate).

## ROI

Baseline time/cost calculated using ROI_Calculator.md. Estimated monthly value. Actual monthly value once live, revisited and corrected over time.

## Engagement History

Key dates, meetings, decisions made specific to this client, and outcomes.

## Lessons

Anything from this client worth logging in the company-wide `13 Lessons Learned.md` — link back to the entry once logged there, don't duplicate the content here.
